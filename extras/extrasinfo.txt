Project Summary: Personal Library Catalog (React + Flask/Tailwind)
	This is a full-stack library management application for personal or small library use. The frontend is built with React and Tailwind CSS, and the backend uses Flask (Python) with a SQL database.

Key Features:
	Add, edit, delete, and view books with rich metadata (title, author, genre, category, tags, cover/preview images, etc.).
	All book and image data is managed exclusively via the backend API—no local storage is used.
	Modern, accessible UI with custom components for forms, lists, and dialogs.
	Export and import book data via the backend.
	Ready for multi-user features and authentication (future enhancement).
	Codebase is refactored for readability, maintainability, and best practices, with clear documentation and editor support.

Tech Stack:
Frontend:
	React (JavaScript, JSX)
	Vite (build tool)
	Tailwind CSS (utility-first CSS framework)
	Lucide React (icon library)
	Custom UI components (in src/components/ui/)
	ESLint (linting)
	pnpm (package manager)

Backend:
	Python 3
	Flask (web framework)
	Flask-CORS (CORS support)
	SQLAlchemy (ORM)
	SQLite (default database, file-based)
	Flask RESTful API (custom endpoints for books, borrowers, lending, export, users, etc.)

Other/Dev Tools:
	VS Code (recommended editor, with tasks and extension support)
	JSDoc (for code documentation)
	Modern JavaScript (ES6+ features)

Project Structure:
	Monorepo-style: library-catalog (frontend), library-catalog-backend (backend)
	All book/image data flows through the backend API—no local storage is used.
